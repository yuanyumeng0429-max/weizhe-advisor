# 马蹄社决策顾问部署说明

这是可直接上传 GitHub、并用 Vercel 重新部署的完整源码包。

## 本次新版变化

1. 网站定位已从「影子董事」改为「马蹄社决策顾问」。
2. 咨询结尾保留原有二维码为第一位，并新增 3 个二维码：
   - 安苔：`assets/qr_anruo.jpg`
   - 马蹄社 · 玉香：`assets/qr_yuxiang.jpg`
   - 紫尘阁 · 致溟：`assets/qr_zhihuan.jpg`
3. 已接入压缩后的马蹄社知识库方法论，包括效率、增长、品牌、AI 硬件、组织、股权、出海、渠道、投资融资等模块。
4. 已强化回答规则：禁止编造事实和数据；案例数字只能来自用户提供、知识库明确事实或联网搜索明确来源。
5. 后台标题与 CSV 导出文件名已同步改为「马蹄社决策顾问」。

## Vercel 环境变量

请在 Vercel 项目设置里保留或新增以下环境变量：

- `QWEN_API_KEY`：通义千问 DashScope API Key，用于聊天回答。
- `FEISHU_WEBHOOK`：飞书群机器人 Webhook，可选，用于线索推送。
- `ADMIN_PASSWORD`：后台查看线索的管理密码。

同时需要在 Vercel 项目里启用 Vercel Blob，因为线索记录会写入 Blob。

## 上传方式

1. 将本源码包解压。
2. 把解压后的全部文件上传到 GitHub 仓库根目录。
3. 在 Vercel 选择该 GitHub 仓库重新部署。
4. 部署后访问首页测试三轮问答，访问 `/admin.html` 测试线索后台。
